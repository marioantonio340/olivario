Política de Privacidade

Olivario Software • olivario.com.br • Vigência 2026/2027

1. Visão Geral e Compromisso

A Olivario Software, sob titularidade de Mário Fernandes, com sede em Patos de Minas, MG, Brasil, compromete-se com a proteção rigorosa da privacidade e dos dados tratados por seu portal institucional (olivario.com.br), softwares, ferramentas de automação e integrações via API.

2. Uso de Dados das APIs Google & YouTube API Services

Nossos aplicativos e ferramentas de automação integram-se aos YouTube API Services e APIs do Google Cloud exclusivamente para gerenciamento, agendamento e publicação de conteúdos em canais autorizados pelo próprio titular.

  • Princípio do Privilégio Mínimo: Solicitamos apenas os escopos estritamente necessários (ex: youtube.upload, youtube.readonly).
  • Sem Comercialização: Não vendemos, alugamos ou transferimos quaisquer dados ou credenciais obtidas via Google APIs para terceiros.
  • Google API Services User Data Policy: O uso e a transferência de informações recebidas das APIs do Google para qualquer outro aplicativo obedecem estritamente à Google API Services User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use).

3. Armazenamento Seguro e Revogação de Acesso

Credenciais e tokens OAuth2 são armazenados de forma segura e local sob controle exclusivo do operador. O usuário pode revogar as permissões concedidas a qualquer instante pela página oficial do Google: myaccount.google.com/permissions.

4. Conformidade com a LGPD (Lei nº 13.709/2018)

Em total respeito à Lei Geral de Proteção de Dados (LGPD), garantimos aos titulares o direito de acesso, confirmação de tratamento, retificação ou eliminação de quaisquer dados pessoais eventualmente tratados.
